# Wireless Pentesting Cheat Sheet

> Follow the [full methodology](../pentesting-methodology/wireless/wireless-penetration-testing.md).

## Scope Gate

- [ ] Site, SSID/BSSID, band, and test location approved
- [ ] Deauthentication/RF disruption explicitly addressed
- [ ] Approved test clients and emergency contact recorded

## Workflow

1. Passive survey
2. Security mode and configuration review
3. Approved association/authentication tests
4. Evil-twin and certificate-validation resistance
5. Guest/client/IoT segmentation
6. Post-association internal assessment
7. Cleanup
