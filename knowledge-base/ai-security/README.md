# AI and LLM Security

This section covers reusable security knowledge for AI, ML, retrieval-augmented generation, and agentic systems.

## Study Order

1. [AI System Reconnaissance](ai-system-reconnaissance.md) — discover what is deployed and exposed.
2. [AI Supply Chains](ai-supply-chains.md) — understand inherited trust across models, data, code, and providers.
3. [AI Supply-Chain Attack Vectors](ai-supply-chain-attack-vectors.md) — analyze unsafe artifacts, dependencies, repositories, and APIs.
4. [Securing the AI Supply Chain](securing-ai-supply-chain.md) — harden acquisition, scanning, promotion, and monitoring.
5. [AI Threat Modelling](ai-threat-modelling.md) — identify threats, assets, and trust boundaries.
6. [AI-Augmented Web Applications](ai-augmented-web-applications.md) — understand AI features inside web architecture.
7. [Prompt Injection](prompt-injection.md) — understand direct and indirect context manipulation.
8. [Jailbreaking](jailbreaking.md) — understand attempts to bypass model safety policies.
9. [Prompt Defence](prompt-defence.md) — reduce injection and jailbreak risk through layered controls.
10. [LLM Pentesting](llm-pentesting.md) — assess authorized LLM application behavior.

## Principle

~~~text
Reconnaissance confirms what exists.
Threat modelling identifies what can go wrong.
Security testing validates specific weaknesses.
Reporting turns evidence into action.
~~~

All techniques require explicit authorization and data-handling controls.
