Using Nmap to discover live hosts, open ports, services and versions accurately and efficiently — the foundation scan almost every assessment starts with.

**Key concepts to own:** host discovery; port scan types; service/version detection; NSE scripts; output formats.

## Deep summary — section by section (original words)

**1. Enumeration** — Systematic discovery of hosts, services, versions, OS and vulnerabilities *before* exploitation. You can't exploit what you don't know exists; the map is what lets you choose and prioritize attacks. Workflow: scope → discover hosts → scan ports → enumerate services → identify vulnerabilities → exploit (later modules). Pitfalls: confusing enumeration with exploitation, skipping discovery, trusting one scan type. *Use: both.*

**2. Introduction to Nmap** — Nmap (free, open-source, since 1997) crafts raw packets to discover hosts/ports/services/versions/OS. Form: `nmap <scan type> <options> <target>`. Raw sockets need root for the stealthy scan types — without it Nmap silently falls back to slower, noisier connect scans. Core flags: `-sS` SYN, `-sT` connect, `-sU` UDP, `-sV` versions, `-O` OS, `-A` aggressive, `-p-` all ports, `--top-ports`, `-Pn` skip discovery, `-v/-vv` verbosity, output `-oN/-oX/-oG`. Always confirm privileges and save results. *Use: both.*

**3. Host Discovery** — Finding live hosts before port scanning. ICMP is often filtered, so a silent host may still be alive: probe types are ping sweep `-sn`, ICMP echo `-PE`, TCP SYN `-PS`, TCP ACK `-PA`, UDP `-PU`, SCTP `-PY`, IP protocol `-PO`, and ARP on the local network (works below IP). `-sL` lists targets without scanning; DNS controls: `-n` (no resolution), `-R`, `--dns-servers`. Route: ICMP first, then TCP SYN/ACK, then UDP; ARP locally. `-Pn` skips discovery but marks every address as up — offline hosts pollute your list. *Use: both.* (1 question — gap.)

**4. Host and Port Scanning** — Port states: Open, Closed, Filtered, Unfiltered, Open|Filtered, Closed|Filtered — the state reveals both the service and the firewall's behaviour. Scan types: `-sT` connect, `-sS` SYN (fast, needs root), `-sU` UDP, `-sA` ACK (maps filtering rules, doesn't find open ports), `-sN/-sF/-sX` NULL/FIN/Xmas, `-sI` idle/zombie. Ranges: `-p-`, `--top-ports <N>`; timing `T0–T5`; `--host-timeout`, `--max-retries`; use `--reason` and `-v` to confirm why a state was reported. Starting practice from the module: T4, retries low (1–2), save output. Pitfalls: no raw-socket privileges, forgetting slow UDP, misreading Open|Filtered as Open. *Use: both.* (2 questions — gap.)

**5. Saving the Results** — Output formats: `-oN` normal (human), `-oX` XML (machine), `-oG` grepable (one line per host), `-oA` all three at once, `-oS` script-kiddie. `--append-output` avoids overwriting; `--resume <file>` restarts an interrupted scan instead of re-scanning; targets can come from files with `-iL`, `--exclude`, `--excludefile`. Workflow: scan with `-oA` → parse with grep/cut/sort/uniq → extract open ports → build target lists → rescan from the list. Pitfall: lost/overwritten output forcing a re-scan of a large network. *Use: both.* (1 question — gap.)

**6. Service Enumeration** — `-sV` identifies the service *and version* via banner grabbing, RPC probes and Nmap's fingerprint database — the version is what maps a service to known vulnerabilities. Tune with `--version-intensity 0–9` (higher = more accurate, slower/noisier), `--version-light`, `--version-all`, and debug unclear results with `--version-trace`. Verify with a manual banner grab where it matters; `-sV` alone can be fooled by banner tricks, and version detection is not vulnerability scanning. *Use: both.* (1 question — gap.)

**7. Nmap Scripting Engine (NSE)** — Lua scripts extend a scan into discovery, auth checks, brute force, vuln checking and more. Categories: auth, broadcast, default, discovery, dos, exploit, external, fuzzer, intrusive, malware, safe, version, vuln. Run with `--script <name|category>`, arguments via `--script-args`, read `--script-help <script>` first, update with `--script-updatedb`; scripts live in `/usr/share/nmap/scripts` and custom ones can be run by path. Start with safe/default categories; the intrusive category can cause denial of service — lab first, authorization always. A script result is a lead, not a proven exploit. *Use: both.* (1 question — gap.)

**8. Performance** — Timing and packet behaviour balance speed, noise and accuracy. Templates `T0` paranoid → `T5` insane, plus fine controls: `--min/max-hostgroup`, `--min/max-parallelism`, `--min/max/initial-rtt-timeout`, `--max-retries`, `--host-timeout`, `--scan-delay / --max-scan-delay`, `--min-rate / --max-rate`, `--defeat-rst-ratelimit`, `--defeat-icmp-ratelimit`. Practice: start T3/T4, tune on a small subset first, match rates to the network — too fast loses packets or gets you banned, too slow never finishes, and retransmission-heavy settings hurt on unreliable links. *Use: both.*

**9. Firewall and IDS/IPS Evasion** — First map the filtering with ACK (`-sA`) and FIN (`-sF`) probes and `--reason`. Evasion toolkit: fragmentation `-f` / `--mtu`, idle scan `-sI <zombie>`, source-port spoofing `-g 53` (or 88), decoys `-D RND:10`, `--spoof-mac`, `--data-length` padding, `--badsum`, `--ttl`, `--scan-delay`, slow timing T0/T1, proxies/relays. Why it works: filters key on flags, source, port and sequence, so fragmenting, slowing, spoofing and decoying make a scan harder to recognize and attribute. Cautions: decoys can implicate other hosts — authorization matters; a ban persists after the first detection; record which method you used. *Use: both.*

**10–12. Evasion Labs (Easy / Medium / Hard)** — A scenario series (read as text only; targets not spawned): a client target sits behind an IDS/IPS with a status page (`http://<target>/status.php`) showing your alert count — too many alerts and you're banned. Easy: check the monitor first, scan quietly (slow timing, scan delay, fragmentation). Medium: same client, tighter blocking — the exercise note says to run the VPN over UDP and scan even quieter. Hard: after the client trained an admin and changed services/communications, everything must be re-enumerated from scratch — stale results from the earlier labs don't carry over. Lesson classes: check the monitor before scanning, adapt evasion to the target as given, treat every test as fresh. (1 question each — gap; Hard is worth 2 flags.)
